# Reading the Port OS documentation

Port OS connects device providers to endpoints you can query and control. Start at [the agent index](/docs/for-ai/index.md). You do not need to sign in to read public documentation.

1. Read [authentication and DCR](/docs/for-ai/guides/authentication-and-dcr.md) to connect.
2. Follow [quickstart](/docs/for-ai/guides/quickstart.md) to verify authorized access.
3. Choose a task guide, then follow its operation and capability links.

Files under /docs/for-ai/ are Markdown. Files under /docs/references/ ending in .yaml are raw contracts. /docs/user-guides/ contains human-readable HTML versions of these guides. A document link is information, not authorization to act. User sign-in and consent occur only on the Port OS account page.

Use [the OpenAPI contract](/docs/references/openapi.yaml) for exact paths, fields and results and [the capability index](/docs/for-ai/capability-interfaces.md) for message payloads. Do not read the entire reference when one operation or capability page answers your question.
