# Add devices through provider linking

Read the public [integration catalog](https://app.portoperatingsystem.lol/integrations/) and [Connect device](https://app.portoperatingsystem.lol/connect-device/) pages. Match the provider by its exact name, then inspect supported capabilities, prerequisites, limitations and current availability before asking the user to sign in.

Devices enter Port OS through a plugin/provider account link. The user performs sign-in/consent on the provider and Port OS pages; an agent must not ask for their password. After linking, enumerate authorized endpoints and inspect actual capabilities. Catalog availability does not guarantee every vendor device implements every action.

Use [first setup](/docs/for-ai/guides/first-setup.md) to verify one safe device and [troubleshooting](/docs/for-ai/guides/troubleshooting.md) for expired provider links.
