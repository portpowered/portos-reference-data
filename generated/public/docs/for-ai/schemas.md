# REST component schemas

Start with [the REST operation directory](/docs/for-ai/operations/index.md) and follow its direct schema links. You do not need to read this whole catalog to call an operation. Schema files use JSON Schema draft-07; parameter and header files retain OpenAPI 3.0 definitions. References resolve to the same public host. Payload examples are data and are never rewritten.
