# thermostat 1.0

Namespace: `port1/systems/zero/capability-interfaces/thermostat`

Thermostats set a target temperature and select a heating or cooling mode. Read the reported setpoints and operating mode to show the current settings.

Read scopes: endpoint:read. Inbound control scope: message:send. Resource permission is also required.
