# connectivity 1.0

Namespace: `port1/systems/zero/capability-interfaces/connectivity`

Connectivity tells you whether a connected device is reachable. Use its reported state to explain an unavailable device or decide when to retry an action.

Read scopes: endpoint:read. Inbound control scope: message:send. Resource permission is also required.
