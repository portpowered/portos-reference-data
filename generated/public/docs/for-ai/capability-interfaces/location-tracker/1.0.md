# location-tracker 1.0

Namespace: `port1/systems/zero/capability-interfaces/location-tracker`

Location trackers start a locator and report its signal. Use them when helping a customer locate a connected item.

Read scopes: endpoint:read. Inbound control scope: message:send. Resource permission is also required.
