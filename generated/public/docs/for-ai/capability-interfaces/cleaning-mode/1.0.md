# cleaning-mode 1.0

Namespace: `port1/systems/zero/capability-interfaces/cleaning-mode`

Cleaning types, suction levels and water flows the robot supports, refreshed on every discovery. set-cleaning-mode values outside these lists are rejected before dispatch.

Read scopes: endpoint:read. Inbound control scope: message:send. Resource permission is also required.

[Complete YAML](/docs/references/capability-interfaces/cleaning-mode/1.0.yaml)

## Messages

- [set-cleaning-mode](/docs/references/capability-interfaces/cleaning-mode/1.0/messages/set-cleaning-mode.yaml) (in): Set whether the robot vacuums, mops or does both, optionally with a suction level and water flow. Omitted levels keep the current non-off value. Values outside the configured supported lists are rejected with 422 before dispatch.
