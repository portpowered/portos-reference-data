# power 1.0

Namespace: `port1/systems/zero/capability-interfaces/power`

Power turns a device on or off, reports its power state, and restarts devices that support rebooting.

Read scopes: endpoint:read. Inbound control scope: message:send. Resource permission is also required.

[Complete YAML](/docs/references/capability-interfaces/power/1.0.yaml)

## Messages

- [reboot](/docs/references/capability-interfaces/power/1.0/messages/reboot.yaml) (in): Restart the endpoint. Advertise this message only when the provider supports rebooting the device.
