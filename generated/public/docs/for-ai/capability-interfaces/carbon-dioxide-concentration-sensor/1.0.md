# carbon-dioxide-concentration-sensor 1.0

Namespace: `port1/systems/zero/capability-interfaces/carbon-dioxide-concentration-sensor`

Carbon dioxide measurements report the concentration observed by a sensor, including its minimum and maximum readings. Use them to track changes in indoor conditions over time.

Read scopes: endpoint:read. Inbound control scope: message:send. Resource permission is also required.
