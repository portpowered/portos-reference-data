# reminders-provider 1.0

Namespace: `port1/systems/zero/capability-interfaces/reminders-provider`

Reminder providers list reminders from a connected account. Use the returned items to give an assistant task context or display an existing reminder list.

Read scopes: endpoint:read. Inbound control scope: message:send. Resource permission is also required.

[Complete YAML](/docs/references/capability-interfaces/reminders-provider/1.0.yaml)

## Messages

- [create-reminder](/docs/references/capability-interfaces/reminders-provider/1.0/messages/create-reminder.yaml) (in): Create a reminder in a discovered list. Creation is sent once; refresh before retrying an uncertain result.
- [create-reminder-response](/docs/references/capability-interfaces/reminders-provider/1.0/messages/create-reminder-response.yaml) (out): The provider accepted the reminder change.
- [delete-reminder](/docs/references/capability-interfaces/reminders-provider/1.0/messages/delete-reminder.yaml) (in): Soft-delete a reminder using its last observed revision.
- [delete-reminder-response](/docs/references/capability-interfaces/reminders-provider/1.0/messages/delete-reminder-response.yaml) (out): The provider accepted soft deletion of the reminder.
- [list-reminders](/docs/references/capability-interfaces/reminders-provider/1.0/messages/list-reminders.yaml) (in): List reminder lists and their reminders. Omit listId to enumerate all lists.
- [list-reminders-response](/docs/references/capability-interfaces/reminders-provider/1.0/messages/list-reminders-response.yaml) (out): Reminder lists and one bounded page of reminders.
- [update-reminder](/docs/references/capability-interfaces/reminders-provider/1.0/messages/update-reminder.yaml) (in): Edit a reminder using its last observed revision; omitted fields are preserved.
- [update-reminder-response](/docs/references/capability-interfaces/reminders-provider/1.0/messages/update-reminder-response.yaml) (out): The provider accepted the reminder change.
