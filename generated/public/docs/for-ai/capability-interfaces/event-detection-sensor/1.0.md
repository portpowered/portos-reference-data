# event-detection-sensor 1.0

Namespace: `port1/systems/zero/capability-interfaces/event-detection-sensor`

Event detection sensors report human presence and emit person-detected events. Use them to give an automation context about activity in a monitored area.

Read scopes: endpoint:read. Inbound control scope: message:send. Resource permission is also required.

[Complete YAML](/docs/references/capability-interfaces/event-detection-sensor/1.0.yaml)

## Messages

- [person-detected](/docs/references/capability-interfaces/event-detection-sensor/1.0/messages/person-detected.yaml) (out): A distinct person detection occurrence, independent of cached presence state.
