# pump-configuration-and-control 1.0

Namespace: `port1/systems/zero/capability-interfaces/pump-configuration-and-control`

Pump controls set a pump mode and speed. Read its capacity, mode, and status to keep a control interface in step with the pump.

Read scopes: endpoint:read. Inbound control scope: message:send. Resource permission is also required.
