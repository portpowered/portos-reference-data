# smoke-co-alarm 1.0

Namespace: `port1/systems/zero/capability-interfaces/smoke-co-alarm`

Smoke and carbon monoxide detectors report detection state. Devices expose alarm controls through the alarm capability and charge level through the battery capability.

Read scopes: endpoint:read. Inbound control scope: message:send. Resource permission is also required.
