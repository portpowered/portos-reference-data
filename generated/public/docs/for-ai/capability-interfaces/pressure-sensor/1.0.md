# pressure-sensor 1.0

Namespace: `port1/systems/zero/capability-interfaces/pressure-sensor`

Pressure measurements report the value supplied by a connected sensor. Use the value and its declared unit when monitoring pressure.

Read scopes: endpoint:read. Inbound control scope: message:send. Resource permission is also required.
