# pm10-concentration-sensor 1.0

Namespace: `port1/systems/zero/capability-interfaces/pm10-concentration-sensor`

PM10 measurements report the concentration observed by a particulate sensor. Use the reported value and unit when displaying air measurements.

Read scopes: endpoint:read. Inbound control scope: message:send. Resource permission is also required.
