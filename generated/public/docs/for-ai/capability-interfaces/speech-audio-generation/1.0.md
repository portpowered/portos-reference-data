# speech-audio-generation 1.0

Namespace: `port1/systems/zero/capability-interfaces/speech-audio-generation`

Speech audio generation turns an input into speech audio and returns it as a short-lived URL or inline base64, chosen with responseFormat. Use the result when an integration needs an audio file it can pass to a player.

Read scopes: endpoint:read. Inbound control scope: message:send. Resource permission is also required.

[Complete YAML](/docs/references/capability-interfaces/speech-audio-generation/1.0.yaml)

## Messages

- [audio-generated](/docs/references/capability-interfaces/speech-audio-generation/1.0/messages/audio-generated.yaml) (out): The speech audio synthesized by generate-speech, as a short-lived URL or inline base64 according to the request's responseFormat
- [generate-speech](/docs/references/capability-interfaces/speech-audio-generation/1.0/messages/generate-speech.yaml) (in): Use this exact payload schema.
