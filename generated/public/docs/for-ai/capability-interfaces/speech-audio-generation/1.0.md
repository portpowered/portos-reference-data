# speech-audio-generation 1.0

Namespace: `port1/systems/zero/capability-interfaces/speech-audio-generation`

Speech audio generation turns an input into speech audio and returns its URI. Use the result when an integration needs an audio file it can pass to a player.

Read scopes: endpoint:read. Inbound control scope: message:send. Resource permission is also required.
