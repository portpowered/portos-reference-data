# wind-speed-sensor 1.0

Namespace: `port1/systems/zero/capability-interfaces/wind-speed-sensor`

Wind speed measurements report the reading supplied by a connected sensor. Use the value and its declared unit when displaying measured wind conditions.

Read scopes: endpoint:read. Inbound control scope: message:send. Resource permission is also required.
