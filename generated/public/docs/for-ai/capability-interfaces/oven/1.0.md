# oven 1.0

Namespace: `port1/systems/zero/capability-interfaces/oven`

Ovens report their temperature. Use the reading to show the temperature supplied by a connected appliance.

Read scopes: endpoint:read. Inbound control scope: message:send. Resource permission is also required.
