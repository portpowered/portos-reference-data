# color-temperature 1.0

Namespace: `port1/systems/zero/capability-interfaces/color-temperature`

Color temperature adjusts a light between warmer and cooler tones. Set a temperature directly or increase and decrease it, then read the reported value in kelvin.

Read scopes: endpoint:read. Inbound control scope: message:send. Resource permission is also required.
