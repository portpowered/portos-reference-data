# light-sensor 1.0

Namespace: `port1/systems/zero/capability-interfaces/light-sensor`

Light sensors report illuminance. Use the reading to understand ambient light and provide input to a lighting automation.

Read scopes: endpoint:read. Inbound control scope: message:send. Resource permission is also required.
