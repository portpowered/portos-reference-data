# rtsp-session 1.0

Namespace: `port1/systems/zero/capability-interfaces/rtsp-session`

RTSP sessions open a camera connection and return its RTSP URI and optional SDP description. Close the session when the connection is no longer needed.

Read scopes: endpoint:read. Inbound control scope: message:send. Resource permission is also required.
