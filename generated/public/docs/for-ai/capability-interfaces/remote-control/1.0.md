# remote-control 1.0

Namespace: `port1/systems/zero/capability-interfaces/remote-control`

Remote control starts and ends control sessions and sends movement instructions. Use velocity, turning, and duration fields to request movement from a connected device.

Read scopes: endpoint:read. Inbound control scope: message:send. Resource permission is also required.
