# cooktop 1.0

Namespace: `port1/systems/zero/capability-interfaces/cooktop`

Cooktops report their operational state. Use that state to show what the appliance is doing or supply context to an automation.

Read scopes: endpoint:read. Inbound control scope: message:send. Resource permission is also required.
