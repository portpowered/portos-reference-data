# window-covering 1.0

Namespace: `port1/systems/zero/capability-interfaces/window-covering`

Window coverings move to a requested lift or tilt percentage. Read their reported position to keep a shade or blind control in step with the device.

Read scopes: endpoint:read. Inbound control scope: message:send. Resource permission is also required.
