# spatial 1.0

Namespace: `port1/systems/zero/capability-interfaces/spatial`

Descriptive spatial declaration of a group route (home, floor/map, room or zone). The spatial interface declares no control messages; cleaning is sent to the robot endpoint.

Read scopes: endpoint:read. Inbound control scope: message:send. Resource permission is also required.
