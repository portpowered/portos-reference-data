# media-playlist 1.0

Namespace: `port1/systems/zero/capability-interfaces/media-playlist`

Media playlists create and manage a collection of items to play. Add or remove items, retrieve a playlist, shuffle it, or ask the device to play it.

Read scopes: endpoint:read. Inbound control scope: message:send. Resource permission is also required.
