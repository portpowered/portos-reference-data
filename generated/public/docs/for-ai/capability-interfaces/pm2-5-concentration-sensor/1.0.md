# pm2-5-concentration-sensor 1.0

Namespace: `port1/systems/zero/capability-interfaces/pm2-5-concentration-sensor`

PM2.5 measurements report the concentration observed by a particulate sensor. Use the reading to follow changes in measured air conditions.

Read scopes: endpoint:read. Inbound control scope: message:send. Resource permission is also required.
