# application-launcher 1.0

Namespace: `port1/systems/zero/capability-interfaces/application-launcher`

Application launchers start and stop applications on a connected device. Check the available applications and the current selection before choosing what to launch.

Read scopes: endpoint:read. Inbound control scope: message:send. Resource permission is also required.
