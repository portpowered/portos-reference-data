# temperature-sensor 1.0

Namespace: `port1/systems/zero/capability-interfaces/temperature-sensor`

Temperature sensors report temperature and operation mode. Use the reading to display conditions or give a heating and cooling flow a measured input.

Read scopes: endpoint:read. Inbound control scope: message:send. Resource permission is also required.
