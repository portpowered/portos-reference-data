# input 1.0

Namespace: `port1/systems/zero/capability-interfaces/input`

Input controls select or navigate between the inputs on a connected device. Read the current input to show which source is selected.

Read scopes: endpoint:read. Inbound control scope: message:send. Resource permission is also required.
