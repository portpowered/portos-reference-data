# authorization 1.0

Namespace: `port1/systems/zero/capability-interfaces/authorization`

Authorization connects an integration to an account and keeps its credentials up to date. Use token refresh and authorization reports to follow the connection as it changes.

Read scopes: endpoint:read. Inbound control scope: message:send. Resource permission is also required.
