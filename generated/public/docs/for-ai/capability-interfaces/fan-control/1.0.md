# fan-control 1.0

Namespace: `port1/systems/zero/capability-interfaces/fan-control`

Fan control selects a fan mode and speed. Read the reported settings to check how a fan is running before changing them.

Read scopes: endpoint:read. Inbound control scope: message:send. Resource permission is also required.
