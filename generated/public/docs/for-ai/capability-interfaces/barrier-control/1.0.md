# barrier-control 1.0

Namespace: `port1/systems/zero/capability-interfaces/barrier-control`

Barrier control opens, closes, or positions a connected barrier. Read its position and state to check a garage door or gate before sending the next command.

Read scopes: endpoint:read. Inbound control scope: message:send. Resource permission is also required.
