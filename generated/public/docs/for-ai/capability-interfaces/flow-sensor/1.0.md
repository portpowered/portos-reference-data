# flow-sensor 1.0

Namespace: `port1/systems/zero/capability-interfaces/flow-sensor`

Flow measurements report the flow observed by a sensor. Use the reading and its declared units to monitor changes in a connected system.

Read scopes: endpoint:read. Inbound control scope: message:send. Resource permission is also required.
