# keypad-input 1.0

Namespace: `port1/systems/zero/capability-interfaces/keypad-input`

Keypad input sends a key to a connected device. Use it to build remote controls that send individual button presses.

Read scopes: endpoint:read. Inbound control scope: message:send. Resource permission is also required.
