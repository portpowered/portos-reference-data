# robotic-vacuum-cleaner 1.0

Namespace: `port1/systems/zero/capability-interfaces/robotic-vacuum-cleaner`

Robotic vacuum cleaners start, pause, stop, and return to their dock. Set a cleaning mode and read the reported mode and operational state to follow a cleaning session.

Read scopes: endpoint:read. Inbound control scope: message:send. Resource permission is also required.

[Complete YAML](/docs/references/capability-interfaces/robotic-vacuum-cleaner/1.0.yaml)

## Messages

- [clean-room](/docs/references/capability-interfaces/robotic-vacuum-cleaner/1.0/messages/clean-room.yaml) (in): Clean one or more rooms, in the requested order. Each entry is a canonical endpoint group the robot can control through a CAN_CONTROL relationship. More than one room requires the configuration to declare supportsMultiRoomCleaning; otherwise the request is rejected with MULTI_ROOM_UNSUPPORTED.
