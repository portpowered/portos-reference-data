# doorbell 1.0

Namespace: `port1/systems/zero/capability-interfaces/doorbell`

Doorbells emit a chime event. Use that event to start a notification or another flow when someone rings the bell.

Read scopes: endpoint:read. Inbound control scope: message:send. Resource permission is also required.

[Complete YAML](/docs/references/capability-interfaces/doorbell/1.0.yaml)

## Messages

- [chime](/docs/references/capability-interfaces/doorbell/1.0/messages/chime.yaml) (out): A distinct doorbell press. A chime does not imply a door was opened.
