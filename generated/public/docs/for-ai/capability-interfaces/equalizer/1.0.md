# equalizer 1.0

Namespace: `port1/systems/zero/capability-interfaces/equalizer`

Equalizers adjust audio bands and select an equalizer mode. Read the current bands and mode to keep an audio control in step with the device.

Read scopes: endpoint:read. Inbound control scope: message:send. Resource permission is also required.
