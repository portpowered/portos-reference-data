# alarm 1.0

Namespace: `port1/systems/zero/capability-interfaces/alarm`

Alarms ring, silence, or test a device's siren when supported. Read the alarm state to see whether the siren is active.

Read scopes: endpoint:read. Inbound control scope: message:send. Resource permission is also required.
