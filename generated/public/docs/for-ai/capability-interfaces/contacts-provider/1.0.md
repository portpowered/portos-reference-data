# contacts-provider 1.0

Namespace: `port1/systems/zero/capability-interfaces/contacts-provider`

Contacts providers list contacts from a connected account. Use the returned records to give an assistant the contact information available to your integration.

Read scopes: endpoint:read. Inbound control scope: message:send. Resource permission is also required.

[Complete YAML](/docs/references/capability-interfaces/contacts-provider/1.0.yaml)

## Messages

- [list-contacts](/docs/references/capability-interfaces/contacts-provider/1.0/messages/list-contacts.yaml) (in): Request to list contacts from a contacts provider
- [list-contacts-response](/docs/references/capability-interfaces/contacts-provider/1.0/messages/list-contacts-response.yaml) (out): Response containing a list of contacts from a contacts provider
