# filesystem-provider 1.0

Namespace: `port1/systems/zero/capability-interfaces/filesystem-provider`

Filesystem providers list folders and photo albums and expose file download, upload, and deletion. Check the provider's supported commands before requesting an operation.

Read scopes: endpoint:read. Inbound control scope: message:send. Resource permission is also required.

[Complete YAML](/docs/references/capability-interfaces/filesystem-provider/1.0.yaml)

## Messages

- [delete-file](/docs/references/capability-interfaces/filesystem-provider/1.0/messages/delete-file.yaml) (in): Delete file.
- [delete-file-response](/docs/references/capability-interfaces/filesystem-provider/1.0/messages/delete-file-response.yaml) (out): The provider confirmed deletion of the requested file.
- [download-file](/docs/references/capability-interfaces/filesystem-provider/1.0/messages/download-file.yaml) (in): Download file.
- [download-file-response](/docs/references/capability-interfaces/filesystem-provider/1.0/messages/download-file-response.yaml) (out): Download file response.
- [list-albums](/docs/references/capability-interfaces/filesystem-provider/1.0/messages/list-albums.yaml) (in): Request to list photo albums from a filesystem provider
- [list-albums-response](/docs/references/capability-interfaces/filesystem-provider/1.0/messages/list-albums-response.yaml) (out): Response containing a list of photo albums from a filesystem provider
- [list-folder](/docs/references/capability-interfaces/filesystem-provider/1.0/messages/list-folder.yaml) (in): Request to list files and folders from a filesystem provider
- [list-folder-response](/docs/references/capability-interfaces/filesystem-provider/1.0/messages/list-folder-response.yaml) (out): Response containing a list of files and folders from a filesystem provider
- [upload-file](/docs/references/capability-interfaces/filesystem-provider/1.0/messages/upload-file.yaml) (in): Upload file.
- [upload-file-response](/docs/references/capability-interfaces/filesystem-provider/1.0/messages/upload-file-response.yaml) (out): Upload file response.
