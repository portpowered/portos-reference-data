# security-pin 1.0

Namespace: `port1/systems/zero/capability-interfaces/security-pin`

Security PINs create, update, query, and delete PIN records. Follow operation results and PIN reports when managing the records supported by a device.

Read scopes: endpoint:read. Inbound control scope: message:send. Resource permission is also required.

[Complete YAML](/docs/references/capability-interfaces/security-pin/1.0.yaml)

## Messages

- [create-pin](/docs/references/capability-interfaces/security-pin/1.0/messages/create-pin.yaml) (in): Create an endpoint-scoped PIN. TEMPORARY requires both validity timestamps; PERMANENT forbids them. Validate increasing, nonexpired instants and declared restrictions before dispatch.
- [delete-pin](/docs/references/capability-interfaces/security-pin/1.0/messages/delete-pin.yaml) (in): Delete a record within the authorized endpoint. Emit a correlated terminal result even when enumeration no longer includes the record.
- [pin-operation-result](/docs/references/capability-interfaces/security-pin/1.0/messages/pin-operation-result.yaml) (out): Correlated safe PIN provisioning result. APPLIED requires vendor-confirmed completion, not dispatch acceptance. CREATE supplies recordId once assigned; UPDATE and DELETE retain the requested ID. FAILED requires a safe code; other statuses forbid code. Never include credentials or raw vendor errors.
- [pin-records-report](/docs/references/capability-interfaces/security-pin/1.0/messages/pin-records-report.yaml) (out): Bounded credential-free record page aligned with the pin-records attribute. Echo the query correlation token in the message header.
- [query-operation](/docs/references/capability-interfaces/security-pin/1.0/messages/query-operation.yaml) (in): Retrieve an endpoint-scoped PIN operation result by its original correlation token. Enforce caller and endpoint ownership. Return pin-operation-result, preserving the original operation correlation token in its payload and using this query's correlation token in the response header.
- [query-pins](/docs/references/capability-interfaces/security-pin/1.0/messages/query-pins.yaml) (in): Query a bounded endpoint-scoped PIN record page. Requires message-send permission. Continuations bind caller, endpoint and page size; return pin-records-report with the request correlation token in its header.
- [update-pin](/docs/references/capability-interfaces/security-pin/1.0/messages/update-pin.yaml) (in): Update an endpoint-scoped record. Require at least one change. Kind is immutable; validity changes require both timestamps and an authoritative TEMPORARY record.
