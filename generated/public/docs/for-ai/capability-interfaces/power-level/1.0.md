# power-level 1.0

Namespace: `port1/systems/zero/capability-interfaces/power-level`

Power level sets or adjusts a device's output level and reports the current setting. Use it when a device supports more than a simple on/off control.

Read scopes: endpoint:read. Inbound control scope: message:send. Resource permission is also required.
