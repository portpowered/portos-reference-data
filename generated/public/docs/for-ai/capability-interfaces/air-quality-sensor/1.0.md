# air-quality-sensor 1.0

Namespace: `port1/systems/zero/capability-interfaces/air-quality-sensor`

Air quality reports the air-quality index measured by a device. Use the reading to understand conditions in a room and decide when to run ventilation or another automation.

Read scopes: endpoint:read. Inbound control scope: message:send. Resource permission is also required.
