# embedding-generation 1.0

Namespace: `port1/systems/zero/capability-interfaces/embedding-generation`

Embedding generation turns an input into an embedding and returns its URI. Use the result in integrations that work with vector representations of content.

Read scopes: endpoint:read. Inbound control scope: message:send. Resource permission is also required.
