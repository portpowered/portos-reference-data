# humidity-sensor 1.0

Namespace: `port1/systems/zero/capability-interfaces/humidity-sensor`

Humidity sensors report relative humidity. Use the reading to display room conditions or provide input to a ventilation or humidifier flow.

Read scopes: endpoint:read. Inbound control scope: message:send. Resource permission is also required.
