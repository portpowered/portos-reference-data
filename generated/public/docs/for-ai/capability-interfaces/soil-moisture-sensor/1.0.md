# soil-moisture-sensor 1.0

Namespace: `port1/systems/zero/capability-interfaces/soil-moisture-sensor`

Soil moisture measurements report the reading supplied by a connected sensor. Use the value as input when monitoring growing conditions.

Read scopes: endpoint:read. Inbound control scope: message:send. Resource permission is also required.
