# color 1.0

Namespace: `port1/systems/zero/capability-interfaces/color`

Color sets and reports the color of a connected device. Use it to coordinate lighting for a scene or let an assistant choose a new color.

Read scopes: endpoint:read. Inbound control scope: message:send. Resource permission is also required.
