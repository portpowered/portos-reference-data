# authorization-requirements 1.0

Namespace: `port1/systems/zero/capability-interfaces/authorization-requirements`

Authorization requirements declare credentials needed by specific endpoint operations. Customers save, replace or remove their camera pattern in endpoint settings; encrypted endpoint state supplies it automatically to permitted camera requests. Query configuration status without retrieving the credential. Never ask for a pattern in chat or include it in RTC payloads.

Read scopes: endpoint:read. Inbound control scope: message:send. Resource permission is also required.

[Complete YAML](/docs/references/capability-interfaces/authorization-requirements/1.0.yaml)

## Messages

- [authorization-status](/docs/references/capability-interfaces/authorization-requirements/1.0/messages/authorization-status.yaml) (out): Redacted saved authorization status. Contains no pattern, PIN or ciphertext.
- [query-authorization](/docs/references/capability-interfaces/authorization-requirements/1.0/messages/query-authorization.yaml) (in): Read configuration status without retrieving any saved value.
- [remove-authorization](/docs/references/capability-interfaces/authorization-requirements/1.0/messages/remove-authorization.yaml) (in): Remove a saved endpoint authorization value. Requires endpoint settings permission; camera access will require configuration again.
- [set-authorization](/docs/references/capability-interfaces/authorization-requirements/1.0/messages/set-authorization.yaml) (in): Set or replace an encrypted endpoint authorization value. Requires endpoint settings permission. Roborock patterns use positions 1–9 in drawing order. Never include this message or its value in public history or diagnostics.
