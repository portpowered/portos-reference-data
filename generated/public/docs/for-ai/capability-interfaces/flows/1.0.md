# flows 1.0

Namespace: `port1/systems/zero/capability-interfaces/flows`

Flows run automations that can be initiated, paused, resumed, or terminated. Follow completion and acknowledgement events to understand the progress of a run.

Read scopes: endpoint:read. Inbound control scope: message:send. Resource permission is also required.
