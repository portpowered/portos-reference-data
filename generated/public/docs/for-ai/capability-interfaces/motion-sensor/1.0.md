# motion-sensor 1.0

Namespace: `port1/systems/zero/capability-interfaces/motion-sensor`

Motion sensors report detection state and emit motion-detected events. Use them to trigger a light, a notification, or another automation when movement is detected.

Read scopes: endpoint:read. Inbound control scope: message:send. Resource permission is also required.

[Complete YAML](/docs/references/capability-interfaces/motion-sensor/1.0.yaml)

## Messages

- [motion-detected](/docs/references/capability-interfaces/motion-sensor/1.0/messages/motion-detected.yaml) (out): A distinct motion occurrence, independent of cached detection state.
