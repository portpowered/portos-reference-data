# recordings 1.0

Namespace: `port1/systems/zero/capability-interfaces/recordings`

Recordings list saved captures and expose recording download and deletion. Use pagination to browse the recordings supplied by a connected provider.

Read scopes: endpoint:read. Inbound control scope: message:send. Resource permission is also required.

[Complete YAML](/docs/references/capability-interfaces/recordings/1.0.yaml)
