# camera 1.0

Namespace: `port1/systems/zero/capability-interfaces/camera`

Cameras provide streaming, event images, and camera controls. Start a stream, adjust pan and tilt when supported, or configure motion detection for the view you need.

Read scopes: endpoint:read. Inbound control scope: message:send. Resource permission is also required.
