# contact-sensor 1.0

Namespace: `port1/systems/zero/capability-interfaces/contact-sensor`

Contact sensors tell you whether a door, window, or gate is open or closed. Use their reported state to check an entryway or trigger an automation when something is left open.

Read scopes: endpoint:read. Inbound control scope: message:send. Resource permission is also required.
