# scene 1.0

Namespace: `port1/systems/zero/capability-interfaces/scene`

Scenes activate or deactivate a predefined device scene. Use them to request a saved combination of settings from a connected integration.

Read scopes: endpoint:read. Inbound control scope: message:send. Resource permission is also required.
