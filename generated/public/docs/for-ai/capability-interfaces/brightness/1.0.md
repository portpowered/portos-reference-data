# brightness 1.0

Namespace: `port1/systems/zero/capability-interfaces/brightness`

Brightness sets how bright a connected device should be and reports its current level. Use it to dim a light for the evening or restore a brighter setting for work.

Read scopes: endpoint:read. Inbound control scope: message:send. Resource permission is also required.
