# battery 1.0

Namespace: `port1/systems/zero/capability-interfaces/battery`

Battery reports a connected device's charge level and battery health. Use it to show when a device needs charging or a replacement battery.

Read scopes: endpoint:read. Inbound control scope: message:send. Resource permission is also required.
