# calendar-provider 1.0

Namespace: `port1/systems/zero/capability-interfaces/calendar-provider`

Calendar providers list events from a connected calendar. Use the returned events to give an assistant schedule context or build an automation around an upcoming appointment.

Read scopes: endpoint:read. Inbound control scope: message:send. Resource permission is also required.

[Complete YAML](/docs/references/capability-interfaces/calendar-provider/1.0.yaml)

## Messages

- [list-events](/docs/references/capability-interfaces/calendar-provider/1.0/messages/list-events.yaml) (in): Request to list events from a calendar provider
- [list-events-response](/docs/references/capability-interfaces/calendar-provider/1.0/messages/list-events-response.yaml) (out): Response containing a list of events from a calendar provider
