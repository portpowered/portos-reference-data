# lock 1.0

Namespace: `port1/systems/zero/capability-interfaces/lock`

Locks accept lock and unlock commands and report their lock state. Use the reported state to check an entryway before requesting a change.

Read scopes: endpoint:read. Inbound control scope: message:send. Resource permission is also required.
