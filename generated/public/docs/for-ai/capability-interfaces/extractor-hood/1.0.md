# extractor-hood 1.0

Namespace: `port1/systems/zero/capability-interfaces/extractor-hood`

Extractor hoods report their fan speed. Use that state to show the current ventilation setting alongside other kitchen appliances.

Read scopes: endpoint:read. Inbound control scope: message:send. Resource permission is also required.
