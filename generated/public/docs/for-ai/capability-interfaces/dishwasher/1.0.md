# dishwasher 1.0

Namespace: `port1/systems/zero/capability-interfaces/dishwasher`

Dishwashers report their operational state. Use it to keep an appliance dashboard up to date or react when a reported state changes.

Read scopes: endpoint:read. Inbound control scope: message:send. Resource permission is also required.
