# snapshot 1.0

Namespace: `port1/systems/zero/capability-interfaces/snapshot`

Snapshots request a captured view and return a snapshot response. Use them when an integration needs a single capture rather than a continuous live view.

Read scopes: endpoint:read. Inbound control scope: message:send. Resource permission is also required.

[Complete YAML](/docs/references/capability-interfaces/snapshot/1.0.yaml)

## Messages

- [get-snapshot](/docs/references/capability-interfaces/snapshot/1.0/messages/get-snapshot.yaml) (in): Request a still image from the camera. responseFormat chooses how the image comes back: URL (default) is a short-lived Port OS link, BASE64 is the image bytes inline.
- [get-snapshot-response](/docs/references/capability-interfaces/snapshot/1.0/messages/get-snapshot-response.yaml) (out): A camera still image, as a short-lived URL or inline base64 according to the request's responseFormat, with the time it was captured
