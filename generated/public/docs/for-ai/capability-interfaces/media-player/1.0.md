# media-player 1.0

Namespace: `port1/systems/zero/capability-interfaces/media-player`

Media players select media by its Port OS media ID, play supplied audio or a URI, and control playback. Read playback state and use only the commands supported by the connected player.

Read scopes: endpoint:read. Inbound control scope: message:send. Resource permission is also required.
