# content-launcher 1.0

Namespace: `port1/systems/zero/capability-interfaces/content-launcher`

Content launchers open content or a URL on a connected device. Use them to send a selected item to a screen or start the content a customer asked for.

Read scopes: endpoint:read. Inbound control scope: message:send. Resource permission is also required.
