# rtc-session 1.0

Namespace: `port1/systems/zero/capability-interfaces/rtc-session`

RTC sessions initiate a connection using an offer and return an answer for the session. Follow disconnection events and close the session when the connection is no longer needed.

Read scopes: endpoint:read. Inbound control scope: message:send. Resource permission is also required.
