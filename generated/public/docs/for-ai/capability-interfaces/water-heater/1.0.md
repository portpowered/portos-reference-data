# water-heater 1.0

Namespace: `port1/systems/zero/capability-interfaces/water-heater`

Water heaters set a temperature and operating mode. Read the temperature setpoint and mode to show the settings supplied by a connected heater.

Read scopes: endpoint:read. Inbound control scope: message:send. Resource permission is also required.
