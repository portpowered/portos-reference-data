# percentage 1.0

Namespace: `port1/systems/zero/capability-interfaces/percentage`

Percentage controls set or adjust a percentage and report the current value. Use them for connected controls expressed as a proportional level.

Read scopes: endpoint:read. Inbound control scope: message:send. Resource permission is also required.
