# control-route-groups-provider 1.0

Namespace: `port1/systems/zero/capability-interfaces/control-route-groups-provider`

Control route groups organize several routes into a group. Create a group with its member routes or delete a group your integration no longer needs.

Read scopes: endpoint:read. Inbound control scope: message:send. Resource permission is also required.

[Complete YAML](/docs/references/capability-interfaces/control-route-groups-provider/1.0.yaml)

## Messages

- [create-group](/docs/references/capability-interfaces/control-route-groups-provider/1.0/messages/create-group.yaml) (in): Request to delete a group based on its group ID. 
- [delete-group](/docs/references/capability-interfaces/control-route-groups-provider/1.0/messages/delete-group.yaml) (in): Request to delete a group based on its group ID.
