# speaker 1.0

Namespace: `port1/systems/zero/capability-interfaces/speaker`

Speakers set or adjust volume and change mute state. Read the current volume and mute state to keep playback controls in step with the device.

Read scopes: endpoint:read. Inbound control scope: message:send. Resource permission is also required.
