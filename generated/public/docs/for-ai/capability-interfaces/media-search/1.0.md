# media-search 1.0

Namespace: `port1/systems/zero/capability-interfaces/media-search`

Media search requests content matching a search and returns audio media results. Use it to find an item before asking a player to play it.

Read scopes: endpoint:read. Inbound control scope: message:send. Resource permission is also required.

[Complete YAML](/docs/references/capability-interfaces/media-search/1.0.yaml)

- [audio-media-results](/docs/references/capability-interfaces/media-search/1.0/messages/audio-media-results.yaml) (out): Use this exact payload schema.
- [get-media](/docs/references/capability-interfaces/media-search/1.0/messages/get-media.yaml) (in): Inspect an exact media resource or traverse an album/show. Use get-playlist for playlist contents.
- [media-details](/docs/references/capability-interfaces/media-search/1.0/messages/media-details.yaml) (out): Exact media resource details and a bounded page of its children.
