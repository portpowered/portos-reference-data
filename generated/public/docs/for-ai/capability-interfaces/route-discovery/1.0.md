# route-discovery 1.0

Namespace: `port1/systems/zero/capability-interfaces/route-discovery`

Route discovery reports the control routes available to an integration. Use its group commands to name a group or update the routes that belong to it.

Read scopes: endpoint:read. Inbound control scope: message:send. Resource permission is also required.

[Complete YAML](/docs/references/capability-interfaces/route-discovery/1.0.yaml)

## Messages

- [add-group-route-members](/docs/references/capability-interfaces/route-discovery/1.0/messages/add-group-route-members.yaml) (in): Request to add members to a group route
- [discover-routes](/docs/references/capability-interfaces/route-discovery/1.0/messages/discover-routes.yaml) (out): Request to discover routes
- [remove-group-route-members](/docs/references/capability-interfaces/route-discovery/1.0/messages/remove-group-route-members.yaml) (in): Request to remove members from a group route
- [route-discovery-report](/docs/references/capability-interfaces/route-discovery/1.0/messages/route-discovery-report.yaml) (out): Report of discovered routes, group routes and their relationships. Decodes to the same model as SynchronizationRequest.
- [set-group-route-name](/docs/references/capability-interfaces/route-discovery/1.0/messages/set-group-route-name.yaml) (in): Request to set the name of a group route
