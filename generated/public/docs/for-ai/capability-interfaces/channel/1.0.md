# channel 1.0

Namespace: `port1/systems/zero/capability-interfaces/channel`

Channel controls select a channel or skip between channels on a connected device. Read the current channel to keep the interface in step with what is playing.

Read scopes: endpoint:read. Inbound control scope: message:send. Resource permission is also required.
