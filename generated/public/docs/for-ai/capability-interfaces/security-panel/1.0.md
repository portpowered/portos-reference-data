# security-panel 1.0

Namespace: `port1/systems/zero/capability-interfaces/security-panel`

Security panels accept arm and disarm commands and report alarm and arming states. Use those reports to show the status supplied by a connected panel.

Read scopes: endpoint:read. Inbound control scope: message:send. Resource permission is also required.
