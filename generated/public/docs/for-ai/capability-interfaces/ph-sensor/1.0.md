# ph-sensor 1.0

Namespace: `port1/systems/zero/capability-interfaces/ph-sensor`

pH measurements report the reading supplied by a connected sensor. Use it when monitoring the conditions of a liquid or growing system.

Read scopes: endpoint:read. Inbound control scope: message:send. Resource permission is also required.
