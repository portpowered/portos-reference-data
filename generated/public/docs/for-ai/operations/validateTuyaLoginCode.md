# validateTuyaLoginCode

POST `/tuya/validatetoken`

Validate Tuya Login Code

Validates a Tuya login code obtained from QR code scanning and returns authentication tokens. After a user scans the QR code generated by the /tuya/qrcode endpoint, this endpoint verifies the login and retrieves the Tuya access and refresh tokens for the authenticated user.
