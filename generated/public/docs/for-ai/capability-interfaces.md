# Capability interfaces

Match the endpoint’s full namespace and version. Message payloads are the body inside the REST message envelope; they are not the entire POST /messages request.

- [air-quality-sensor 1.0](/docs/for-ai/capability-interfaces/air-quality-sensor/1.0.md): Air quality reports the air-quality index measured by a device. Use the reading to understand conditions in a room and decide when to run ventilation or another automation.
- [alarm 1.0](/docs/for-ai/capability-interfaces/alarm/1.0.md): Alarms ring, silence, or test a device's siren when supported. Read the alarm state to see whether the siren is active.
- [application-launcher 1.0](/docs/for-ai/capability-interfaces/application-launcher/1.0.md): Application launchers start and stop applications on a connected device. Check the available applications and the current selection before choosing what to launch.
- [authorization 1.0](/docs/for-ai/capability-interfaces/authorization/1.0.md): Authorization connects an integration to an account and keeps its credentials up to date. Use token refresh and authorization reports to follow the connection as it changes.
- [barrier-control 1.0](/docs/for-ai/capability-interfaces/barrier-control/1.0.md): Barrier control opens, closes, or positions a connected barrier. Read its position and state to check a garage door or gate before sending the next command.
- [battery 1.0](/docs/for-ai/capability-interfaces/battery/1.0.md): Battery reports a connected device's charge level and battery health. Use it to show when a device needs charging or a replacement battery.
- [brightness 1.0](/docs/for-ai/capability-interfaces/brightness/1.0.md): Brightness sets how bright a connected device should be and reports its current level. Use it to dim a light for the evening or restore a brighter setting for work.
- [calendar-provider 1.0](/docs/for-ai/capability-interfaces/calendar-provider/1.0.md): Calendar providers list events from a connected calendar. Use the returned events to give an assistant schedule context or build an automation around an upcoming appointment.
- [camera 1.0](/docs/for-ai/capability-interfaces/camera/1.0.md): Cameras provide streaming, event images, and camera controls. Start a stream, adjust pan and tilt when supported, or configure motion detection for the view you need.
- [carbon-dioxide-concentration-sensor 1.0](/docs/for-ai/capability-interfaces/carbon-dioxide-concentration-sensor/1.0.md): Carbon dioxide measurements report the concentration observed by a sensor, including its minimum and maximum readings. Use them to track changes in indoor conditions over time.
- [carbon-monoxide-concentration-sensor 1.0](/docs/for-ai/capability-interfaces/carbon-monoxide-concentration-sensor/1.0.md): Carbon monoxide measurements report the concentration observed by a sensor, including its minimum and maximum readings. Use the reported values as input to monitoring and notification flows.
- [channel 1.0](/docs/for-ai/capability-interfaces/channel/1.0.md): Channel controls select a channel or skip between channels on a connected device. Read the current channel to keep the interface in step with what is playing.
- [cleaning-mode 1.0](/docs/for-ai/capability-interfaces/cleaning-mode/1.0.md): Cleaning types, suction levels and water flows the robot supports, refreshed on every discovery. set-cleaning-mode values outside these lists are rejected before dispatch.
- [color 1.0](/docs/for-ai/capability-interfaces/color/1.0.md): Color sets and reports the color of a connected device. Use it to coordinate lighting for a scene or let an assistant choose a new color.
- [color-temperature 1.0](/docs/for-ai/capability-interfaces/color-temperature/1.0.md): Color temperature adjusts a light between warmer and cooler tones. Set a temperature directly or increase and decrease it, then read the reported value in kelvin.
- [connectivity 1.0](/docs/for-ai/capability-interfaces/connectivity/1.0.md): Connectivity tells you whether a connected device is reachable. Use its reported state to explain an unavailable device or decide when to retry an action.
- [contact-sensor 1.0](/docs/for-ai/capability-interfaces/contact-sensor/1.0.md): Contact sensors tell you whether a door, window, or gate is open or closed. Use their reported state to check an entryway or trigger an automation when something is left open.
- [contacts-provider 1.0](/docs/for-ai/capability-interfaces/contacts-provider/1.0.md): Contacts providers list contacts from a connected account. Use the returned records to give an assistant the contact information available to your integration.
- [content-launcher 1.0](/docs/for-ai/capability-interfaces/content-launcher/1.0.md): Content launchers open content or a URL on a connected device. Use them to send a selected item to a screen or start the content a customer asked for.
- [control-route-groups-provider 1.0](/docs/for-ai/capability-interfaces/control-route-groups-provider/1.0.md): Control route groups organize several routes into a group. Create a group with its member routes or delete a group your integration no longer needs.
- [control-routes-provider 1.0](/docs/for-ai/capability-interfaces/control-routes-provider/1.0.md): Control route providers carry dispatch results and attribute reports between an integration and Port OS. Use them to report acknowledgements, errors, deferred responses, and batches of messages.
- [cooktop 1.0](/docs/for-ai/capability-interfaces/cooktop/1.0.md): Cooktops report their operational state. Use that state to show what the appliance is doing or supply context to an automation.
- [dishwasher 1.0](/docs/for-ai/capability-interfaces/dishwasher/1.0.md): Dishwashers report their operational state. Use it to keep an appliance dashboard up to date or react when a reported state changes.
- [doorbell 1.0](/docs/for-ai/capability-interfaces/doorbell/1.0.md): Doorbells emit a chime event. Use that event to start a notification or another flow when someone rings the bell.
- [electrical-conductivity-sensor 1.0](/docs/for-ai/capability-interfaces/electrical-conductivity-sensor/1.0.md): Electrical conductivity measurements report a sensor reading. Use the value and its declared units when displaying or comparing measurements.
- [embedding-generation 1.0](/docs/for-ai/capability-interfaces/embedding-generation/1.0.md): Embedding generation turns an input into an embedding and returns its URI. Use the result in integrations that work with vector representations of content.
- [endpoint-registry 1.0](/docs/for-ai/capability-interfaces/endpoint-registry/1.0.md): Configuration for Port OS endpoint registry lifecycle notifications
- [equalizer 1.0](/docs/for-ai/capability-interfaces/equalizer/1.0.md): Equalizers adjust audio bands and select an equalizer mode. Read the current bands and mode to keep an audio control in step with the device.
- [event-detection-sensor 1.0](/docs/for-ai/capability-interfaces/event-detection-sensor/1.0.md): Event detection sensors report human presence and emit person-detected events. Use them to give an automation context about activity in a monitored area.
- [extractor-hood 1.0](/docs/for-ai/capability-interfaces/extractor-hood/1.0.md): Extractor hoods report their fan speed. Use that state to show the current ventilation setting alongside other kitchen appliances.
- [fan-control 1.0](/docs/for-ai/capability-interfaces/fan-control/1.0.md): Fan control selects a fan mode and speed. Read the reported settings to check how a fan is running before changing them.
- [filesystem-provider 1.0](/docs/for-ai/capability-interfaces/filesystem-provider/1.0.md): Filesystem providers list folders and photo albums and expose file download, upload, and deletion. Check the provider's supported commands before requesting an operation.
- [flow-sensor 1.0](/docs/for-ai/capability-interfaces/flow-sensor/1.0.md): Flow measurements report the flow observed by a sensor. Use the reading and its declared units to monitor changes in a connected system.
- [flows 1.0](/docs/for-ai/capability-interfaces/flows/1.0.md): Flows run automations that can be initiated, paused, resumed, or terminated. Follow completion and acknowledgement events to understand the progress of a run.
- [formaldehyde-concentration-sensor 1.0](/docs/for-ai/capability-interfaces/formaldehyde-concentration-sensor/1.0.md): Formaldehyde measurements report the concentration observed by a sensor. Use the reading and its declared unit when presenting environmental measurements.
- [humidity-sensor 1.0](/docs/for-ai/capability-interfaces/humidity-sensor/1.0.md): Humidity sensors report relative humidity. Use the reading to display room conditions or provide input to a ventilation or humidifier flow.
- [input 1.0](/docs/for-ai/capability-interfaces/input/1.0.md): Input controls select or navigate between the inputs on a connected device. Read the current input to show which source is selected.
- [keypad-input 1.0](/docs/for-ai/capability-interfaces/keypad-input/1.0.md): Keypad input sends a key to a connected device. Use it to build remote controls that send individual button presses.
- [laundry-dryer 1.0](/docs/for-ai/capability-interfaces/laundry-dryer/1.0.md): Laundry dryers report their operational state. Use it to show the current appliance status or react to a change in a flow.
- [laundry-washer 1.0](/docs/for-ai/capability-interfaces/laundry-washer/1.0.md): Laundry washers report their operational state. Use it to keep a laundry dashboard in step with the appliance.
- [leaf-wetness-sensor 1.0](/docs/for-ai/capability-interfaces/leaf-wetness-sensor/1.0.md): Leaf wetness measurements report readings from a connected sensor. Use them as input when monitoring plants and growing conditions.
- [light-sensor 1.0](/docs/for-ai/capability-interfaces/light-sensor/1.0.md): Light sensors report illuminance. Use the reading to understand ambient light and provide input to a lighting automation.
- [location 1.0](/docs/for-ai/capability-interfaces/location/1.0.md): Location reports a connected resource's geolocation. Use it to show the position supplied by that resource.
- [location-tracker 1.0](/docs/for-ai/capability-interfaces/location-tracker/1.0.md): Location trackers start a locator and report its signal. Use them when helping a customer locate a connected item.
- [lock 1.0](/docs/for-ai/capability-interfaces/lock/1.0.md): Locks accept lock and unlock commands and report their lock state. Use the reported state to check an entryway before requesting a change.
- [media-player 1.0](/docs/for-ai/capability-interfaces/media-player/1.0.md): Media players select media by its Port OS media ID, play supplied audio or a URI, and control playback. Read playback state and use only the commands supported by the connected player.
- [media-playlist 1.0](/docs/for-ai/capability-interfaces/media-playlist/1.0.md): Media playlists create and manage a collection of items to play. Add or remove items, retrieve a playlist, shuffle it, or ask the device to play it.
- [media-search 1.0](/docs/for-ai/capability-interfaces/media-search/1.0.md): Media search requests content matching a search and returns audio media results. Use it to find an item before asking a player to play it.
- [microwave-oven 1.0](/docs/for-ai/capability-interfaces/microwave-oven/1.0.md): Microwave ovens report their operational state. Use that state to show what the appliance is currently doing.
- [motion-sensor 1.0](/docs/for-ai/capability-interfaces/motion-sensor/1.0.md): Motion sensors report detection state and emit motion-detected events. Use them to trigger a light, a notification, or another automation when movement is detected.
- [nitrogen-dioxide-concentration-sensor 1.0](/docs/for-ai/capability-interfaces/nitrogen-dioxide-concentration-sensor/1.0.md): Nitrogen dioxide measurements report the concentration observed by a sensor. Use the value and its declared units in environmental monitoring.
- [notification 1.0](/docs/for-ai/capability-interfaces/notification/1.0.md): Notifications can be triggered immediately or scheduled. Follow notification events to connect the delivery flow to the rest of an integration.
- [oven 1.0](/docs/for-ai/capability-interfaces/oven/1.0.md): Ovens report their temperature. Use the reading to show the temperature supplied by a connected appliance.
- [ozone-concentration-sensor 1.0](/docs/for-ai/capability-interfaces/ozone-concentration-sensor/1.0.md): Ozone measurements report the concentration observed by a sensor. Use the reading and its declared unit when displaying environmental conditions.
- [percentage 1.0](/docs/for-ai/capability-interfaces/percentage/1.0.md): Percentage controls set or adjust a percentage and report the current value. Use them for connected controls expressed as a proportional level.
- [pet-feeder 1.0](/docs/for-ai/capability-interfaces/pet-feeder/1.0.md): Pet feeders accept a command to trigger a feed. Use the command to start a feeding action from an interface or automation.
- [ph-sensor 1.0](/docs/for-ai/capability-interfaces/ph-sensor/1.0.md): pH measurements report the reading supplied by a connected sensor. Use it when monitoring the conditions of a liquid or growing system.
- [pm10-concentration-sensor 1.0](/docs/for-ai/capability-interfaces/pm10-concentration-sensor/1.0.md): PM10 measurements report the concentration observed by a particulate sensor. Use the reported value and unit when displaying air measurements.
- [pm2-5-concentration-sensor 1.0](/docs/for-ai/capability-interfaces/pm2-5-concentration-sensor/1.0.md): PM2.5 measurements report the concentration observed by a particulate sensor. Use the reading to follow changes in measured air conditions.
- [power 1.0](/docs/for-ai/capability-interfaces/power/1.0.md): Power turns a device on or off, reports its power state, and restarts devices that support rebooting.
- [power-level 1.0](/docs/for-ai/capability-interfaces/power-level/1.0.md): Power level sets or adjusts a device's output level and reports the current setting. Use it when a device supports more than a simple on/off control.
- [pressure-sensor 1.0](/docs/for-ai/capability-interfaces/pressure-sensor/1.0.md): Pressure measurements report the value supplied by a connected sensor. Use the value and its declared unit when monitoring pressure.
- [pump-configuration-and-control 1.0](/docs/for-ai/capability-interfaces/pump-configuration-and-control/1.0.md): Pump controls set a pump mode and speed. Read its capacity, mode, and status to keep a control interface in step with the pump.
- [recordings 1.0](/docs/for-ai/capability-interfaces/recordings/1.0.md): Recordings list saved captures and expose recording download and deletion. Use pagination to browse the recordings supplied by a connected provider.
- [refrigerator 1.0](/docs/for-ai/capability-interfaces/refrigerator/1.0.md): Refrigerators report their temperature. Use the reading to show the conditions supplied by the appliance.
- [reminders-provider 1.0](/docs/for-ai/capability-interfaces/reminders-provider/1.0.md): Reminder providers list reminders from a connected account. Use the returned items to give an assistant task context or display an existing reminder list.
- [remote-control 1.0](/docs/for-ai/capability-interfaces/remote-control/1.0.md): Remote control starts and ends control sessions and sends movement instructions. Use velocity, turning, and duration fields to request movement from a connected device.
- [robotic-vacuum-cleaner 1.0](/docs/for-ai/capability-interfaces/robotic-vacuum-cleaner/1.0.md): Robotic vacuum cleaners start, pause, stop, and return to their dock. Set a cleaning mode and read the reported mode and operational state to follow a cleaning session.
- [route-discovery 1.0](/docs/for-ai/capability-interfaces/route-discovery/1.0.md): Route discovery reports the control routes available to an integration. Use its group commands to name a group or update the routes that belong to it.
- [rtc-session 1.0](/docs/for-ai/capability-interfaces/rtc-session/1.0.md): RTC sessions initiate a connection using an offer and return an answer for the session. Follow disconnection events and close the session when the connection is no longer needed.
- [rtsp-session 1.0](/docs/for-ai/capability-interfaces/rtsp-session/1.0.md): RTSP sessions open a camera connection and return its RTSP URI and optional SDP description. Close the session when the connection is no longer needed.
- [scene 1.0](/docs/for-ai/capability-interfaces/scene/1.0.md): Scenes activate or deactivate a predefined device scene. Use them to request a saved combination of settings from a connected integration.
- [security-panel 1.0](/docs/for-ai/capability-interfaces/security-panel/1.0.md): Security panels accept arm and disarm commands and report alarm and arming states. Use those reports to show the status supplied by a connected panel.
- [security-pin 1.0](/docs/for-ai/capability-interfaces/security-pin/1.0.md): Security PINs create, update, query, and delete PIN records. Follow operation results and PIN reports when managing the records supported by a device.
- [smoke-co-alarm 1.0](/docs/for-ai/capability-interfaces/smoke-co-alarm/1.0.md): Smoke and carbon monoxide detectors report detection state. Devices expose alarm controls through the alarm capability and charge level through the battery capability.
- [snapshot 1.0](/docs/for-ai/capability-interfaces/snapshot/1.0.md): Snapshots request a captured view and return a snapshot response. Use them when an integration needs a single capture rather than a continuous live view.
- [soil-moisture-sensor 1.0](/docs/for-ai/capability-interfaces/soil-moisture-sensor/1.0.md): Soil moisture measurements report the reading supplied by a connected sensor. Use the value as input when monitoring growing conditions.
- [spatial 1.0](/docs/for-ai/capability-interfaces/spatial/1.0.md): Descriptive spatial declaration of a group route (home, floor/map, room or zone). The spatial interface declares no control messages; cleaning is sent to the robot endpoint.
- [speaker 1.0](/docs/for-ai/capability-interfaces/speaker/1.0.md): Speakers set or adjust volume and change mute state. Read the current volume and mute state to keep playback controls in step with the device.
- [speech-audio-generation 1.0](/docs/for-ai/capability-interfaces/speech-audio-generation/1.0.md): Speech audio generation turns an input into speech audio and returns its URI. Use the result when an integration needs an audio file it can pass to a player.
- [speech-synthesizer 1.0](/docs/for-ai/capability-interfaces/speech-synthesizer/1.0.md): Speech synthesizers accept a request to speak. Use them to send spoken output to a connected device or integration.
- [temperature-sensor 1.0](/docs/for-ai/capability-interfaces/temperature-sensor/1.0.md): Temperature sensors report temperature and operation mode. Use the reading to display conditions or give a heating and cooling flow a measured input.
- [text 1.0](/docs/for-ai/capability-interfaces/text/1.0.md): Text sends a text message to a connected component. Use it to pass written input between integrations.
- [text-stream 1.0](/docs/for-ai/capability-interfaces/text-stream/1.0.md): Text streams emit text as a stream of messages. Use the stream to consume output as it becomes available.
- [thermostat 1.0](/docs/for-ai/capability-interfaces/thermostat/1.0.md): Thermostats set a target temperature and select a heating or cooling mode. Read the reported setpoints and operating mode to show the current settings.
- [water-heater 1.0](/docs/for-ai/capability-interfaces/water-heater/1.0.md): Water heaters set a temperature and operating mode. Read the temperature setpoint and mode to show the settings supplied by a connected heater.
- [wind-speed-sensor 1.0](/docs/for-ai/capability-interfaces/wind-speed-sensor/1.0.md): Wind speed measurements report the reading supplied by a connected sensor. Use the value and its declared unit when displaying measured wind conditions.
- [window 1.0](/docs/for-ai/capability-interfaces/window/1.0.md): Windows report their window state and lock state. Use those reports to check the status supplied by a connected window.
- [window-covering 1.0](/docs/for-ai/capability-interfaces/window-covering/1.0.md): Window coverings move to a requested lift or tilt percentage. Read their reported position to keep a shade or blind control in step with the device.
